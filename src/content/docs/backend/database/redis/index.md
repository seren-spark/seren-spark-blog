## 推荐使用方法

- 第一遍按顺序完成第 1–8 章，亲手运行每章的 redis-cli 或 Java 示例。
- 第二遍学习第 9–11 章，用 INFO、SLOWLOG、MEMORY USAGE 等命令观察自己的实例。
- 最后不看答案完成第 12 章的场景推演；能讲清方案的边界，比背下所有命令更重要。

## 配套视频

内容主题参考了[黑马程序员 Redis 入门到实战教程](https://www.bilibili.com/video/BV1cr4y1671t/)，正文与示例为独立整理。视频共 175 节，第一轮不必完整学习源码、手写网络客户端和 OpenResty 多级缓存部分。每一章末尾都给出了对应的选学分集与官方资料。

## 版本与验证

主线按 Redis 8.2、Java 17、Spring Boot 3.5.x 讲解，大多数核心用法也适用于 Redis 7.x。示例中的延迟、容量和 TTL 是教学假设；真实项目需要根据流量、正确性和接口预算验证。
